# Mandatory startup instructions

Before doing ANYTHING — before reading other project files, before planning, before writing code, before answering questions — read context from `Shared_Brain/`:

1. Run `git pull` inside `Shared_Brain/`
2. Read `Shared_Brain/agents.md` and follow its instructions
3. Read `Shared_Brain/memory/goal.md` (if present)
4. Read `Shared_Brain/memory/decisions.md` (if present)
5. Read your assigned task file under `Shared_Brain/` (if present)
6. Never modify `Shared_Brain/memory/goal.md` directly
7. Commit every completed task in `Shared_Brain/` when applicable
8. Run `git pull` again inside `Shared_Brain/` before pushing
9. Resolve any conflicts before `git push`

Do not proceed with the user's request until Shared_Brain context has been loaded.
