# Mandatory startup instructions

Before doing ANYTHING — before reading other project files, before planning, before writing code, before answering questions — read context from `Shared_Brain/`:

1. Verify that `Shared_Brain/` exists at the root of this repository. If it is missing, **stop immediately** — do not continue with any task, planning, or code changes. Tell the user that `Shared_Brain` is required at the project root and must be present before work can proceed.
2. Run `git pull` inside `Shared_Brain/`
3. Read `Shared_Brain/agents.md` and follow its instructions
4. Read `Shared_Brain/memory/goal.md` (if present)
5. Read `Shared_Brain/memory/decisions.md` (if present)
6. Read your assigned task file under `Shared_Brain/` (if present)
7. Never modify `Shared_Brain/memory/goal.md` directly
8. Commit every completed task in `Shared_Brain/` when applicable
9. Run `git pull` again inside `Shared_Brain/` before pushing
10. Resolve any conflicts before `git push`

Do not proceed with the user's request until Shared_Brain context has been loaded.
